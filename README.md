# SuperStore-Sales-Dashboard - Power BI

<img width="1298" height="733" alt="Screenshot 2026-05-23 043917" src="https://github.com/user-attachments/assets/79086544-ddad-4a90-a6e7-38e673d78fdb" />


This project is an Interactive SuperStore Sales Dashboard developed using Microsoft Power BI to analyze sales performance and generate meaningful business insights from retail data.

📌 Features
Sales, Orders & Profit Analysis
Sales by Region, Segment & Payment Mode
Monthly Sales & Profit Trends
Shipping Mode Performance Analysis
Category & Sub-Category Sales Insights
State-wise Sales Visualization (Map)
Interactive Region Filters
🛠 Tools & Technologies Used
Microsoft Power BI
Power Query (Data Cleaning & Transformation)
DAX (Data Analysis Expressions)
Data Visualization Techniques
📊 Key Insights
Analyzed sales trends across different months.
Compared profits and sales performance.
Identified top-performing categories and sub-categories.
Evaluated regional sales distribution and shipping preferences.
🎯 Objective

The main objective of this project is to transform raw retail sales data into interactive and visually appealing dashboards to support better business decision-making.

Data Cleaning
Data Modeling
Dashboard Designing
Business Intelligence
Data Visualization
DAX Calculations
